Light Skirmish

large interactive game
2018

Interactive two-player game comprised of a circular array of wifi-controlled multi-color LED stage lights and two large wireless nautical steering wheels. Players face one another across the circle and must spin their wheel… causing lights to illuminate in a series around the loop. The "spinning" lights decrease in speed with the game's goal to stop on the opposing player. This game was built using Wemos Arduino micro-controllers inserted into 24 outdoor 10W/12V LED flood lights, powered by lithium battery packs. Installed at Electric Sky Art Camp and Burien Arts-A-Glow.

A computer controlled graphical fountain that "prints" designs using falling drops of water. Audio input allows participants to interact with the fountain and influence the designs produced. Night Balloons

glowing orb array
2013

A string of balloon lanterns, each with a microchipped RGB LED bulb, making them controllable inflatable light bulbs synchronized from an Arduino processor on the ground. The light patterns and simulated motion is done via phone/ethernet cords and connection terminals. This piece has been setup with helium as single vertical chain as well as in a 3D geometric (tetrahedron) array.

Steve the Robot H.E.Ai.D.

interactive audio experience
2010

A large-scale, interactive, collaborative audio installation in which people moved to control lasers generate music together. Short for Human Energized Artificial Intelligence Device— the project was intended as a new type of instrument played both as an individual and/or within a group. Because sound was created by simple movement the barrier to participation was low, and emergent collaborative exploration often became the focus.

Radioator

mobile broadcast cart
2007

A mobile radio station built on a golf cart chassis that broadcast mobile FM (25mW). It allowed vehicles and people to synchronize nearby; sometimes silently using ear phones (50 provided to guests), as well as synchronizing disparate speaker systems. The cart frame was made to look like a giant 12 foot set of headphones in bright chartreuse using two fold-out hemispheres and a connecting arch tubes.
