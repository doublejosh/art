## File Types

Each folder can contain:
- Images (JPG, PNG, GIF)
- Videos (MP4, MOV)
- Documents (PDF)
- Other media files related to the project

## Usage

To add media for a project:
1. Navigate to the appropriate project folder
2. Add your media files with descriptive names
3. Update the project links in `projects.js` to reference the local files if needed

Example:
```
media/whiskey-oclock/
├── prototype-video.mov
├── full-scale-draft.jpg
├── installation-photo.jpg
└── process-shots/
    ├── bottles-collection.jpg
    └── wiring-setup.jpg
```
